# ☕ Coffee House - Responsive Coffee Shop Website

A modern, visually appealing, and fully responsive coffee shop website built using clean HTML5, CSS3, and JavaScript[cite: 27, 28]. Features an interactive product showcase, smooth customer review slider using Swiper.js, and an intuitive mobile navigation system[cite: 27, 28].

---

## 🌟 Features

- **Responsive Hero Section:** Engaging landing banner with call-to-action buttons and coffee highlights[cite: 27, 28].
- **Interactive Navigation Bar:** Fixed navigation header with mobile drawer menu support[cite: 27, 28].
- **About Us Section:** Background story, values, and integrated social media links[cite: 27].
- **Menu Showcase:** Categorized item display (Hot Beverages, Cold Beverages, Combos, Desserts, and Quick Bites)[cite: 27].
- **Customer Testimonials Slider:** Smooth carousel slider powered by Swiper.js with custom pagination dots and navigation buttons[cite: 27, 28].
- **Image Gallery:** Visual gallery featuring coffee items and cafe atmosphere[cite: 27].
- **Contact & Location:** Operating hours, address, direct inquiry form, and location details[cite: 27].
- **Cross-Device Compatibility:** Optimized for desktop, tablet, and mobile screen layouts[cite: 28].
