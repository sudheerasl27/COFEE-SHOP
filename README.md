# ☕ Coffee House - Responsive Coffee Shop Website

A modern, visually appealing, and fully responsive coffee shop website built using clean HTML5, CSS3, and JavaScript.
.Features an interactive product showcase, smooth customer review slider using Swiper.js, and an intuitive mobile navigation system.

---

## 🌟 Features

- **Responsive Hero Section:** Engaging landing banner with call-to-action buttons and coffee highlights
- **Interactive Navigation Bar:** Fixed navigation header with mobile drawer menu support.
- **About Us Section:** Background story, values, and integrated social media links.
- **Menu Showcase:** Categorized item display (Hot Beverages, Cold Beverages, Combos, Desserts, and Quick Bites).
- **Customer Testimonials Slider:** Smooth carousel slider powered by Swiper.js with custom pagination dots and navigation buttons.
- **Image Gallery:** Visual gallery featuring coffee items and cafe atmosphere.
- **Contact & Location:** Operating hours, address, direct inquiry form, and location details.
- **Cross-Device Compatibility:** Optimized for desktop, tablet, and mobile screen layouts.

---

## 🛠️ Built With

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom CSS variables, Flexbox layouts, media queries, and smooth hover animations.
- **JavaScript:** Mobile menu toggle logic and Swiper.js initialization.
- **Swiper.js:** Touch-enabled slider for customer testimonials.
- **Font Awesome:** Social media and UI iconography.
